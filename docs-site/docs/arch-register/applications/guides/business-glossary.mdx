# Business Glossary

The Business Glossary application helps members find and review governed business terms. It uses the workspace's
entity schemas for term and category data, while providing glossary-specific search, quality filters, and usage
information.

## Open the glossary

Select **Business Glossary** from the application switcher. The app is available when the member has application access.
If the app is unavailable, ask a workspace administrator to check the
[application access policy](../../admin/roles-permissions#application-access).

## Find terms

Search by a term's canonical name, synonym, or abbreviation. Select one or more categories in the sidebar, choose a
quality facet, or use **Owner / Lifecycle** to narrow the results. Quality facets identify terms that are unused
(no visible references found), conflicting (a name or alias is shared), deprecated (uses the deprecated lifecycle
state), or missing an owner. Remove an active filter or clear the selection to broaden the results again.

Sort the table by name, usage count, or status. Select a term row to open its entity drawer and review its definition,
metadata, categories, quality indicators, and visible usage. Use **Open record in Entities** when you need the full
entity screen or want to edit the term. For the workspace-wide search surface, supported result types, and navigation
behavior, see [Search](../../use/search#business-glossary-term-search).

## Create and maintain terms

Term definitions, aliases, categories, ownership, lifecycle, and status are maintained as entity data. Create or edit
terms from **Entities** using the glossary Term schema; manage category records through the Term Category schema. Existing entity permissions, history, and approval workflows apply. See [Entities](../../use/entities),
[Data Modeling and Schemas](../../use/data-modeling-schemas), and [Governance and Approvals](../../use/governance).

## Review term usage

The glossary reports usage across entities, typed relations, Markdown, projects, and diagrams. Usage is permission-aware,
so the report only exposes material the current member can access. Use these reports alongside the term quality filters
to identify records that may need an owner, a definition, or a status review.
