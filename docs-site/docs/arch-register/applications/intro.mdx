# Application Guides

Arch Register workspaces are organized into applications alongside the Home register. Applications organize domain
workflows around the same workspace catalog, while using their own sections, dashboards, and access policies.

An application appears to a member when its access policy allows that member to use it. Workspace administrators manage
access under **Workspace Settings → Applications & Capabilities**. See
[Roles and Permissions](../admin/roles-permissions#application-access) for how application access relates to workspace
and team permissions.

Applications and their dashboards are workspace data. The built-in applications are created with every workspace, and
users with dashboard-management rights can add, rename, recolour, and delete applications, or add, rename, re-icon,
reorder, and delete dashboards from an application's left rail. Applications travel with the workspace in
[export and import](../admin/export-import).

Each guide describes setup prerequisites, access, available sections, and how the application uses shared entities and
typed relations. Some sections depend on other workspace configuration; the guides call out these
dependencies and any workflow that is still incomplete.
