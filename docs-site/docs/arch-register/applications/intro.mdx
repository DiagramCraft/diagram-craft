# Application Guides

Arch Register workspaces can enable optional applications alongside the Home register. Applications organize domain
workflows around the same workspace catalog, while using their own sections and access policies.

An application appears to a member when its workspace capability is configured and its access policy allows that
member to use it. Workspace administrators manage these settings under **Workspace Settings → Applications &
Capabilities**. See [Roles and Permissions](../admin/roles-permissions#application-access) for how application access
relates to workspace and team permissions.

## Choose an application guide

- [Business Glossary](guides/business-glossary) — find and review governed terms.
- [Strategy & Capability Modelling](guides/strategy-capability-modelling) — map business capabilities to objectives,
  initiatives, outcomes, measures, and supporting applications.
- [Vendor Management](guides/vendor-management) — review vendors, contracts, renewals, spend, and vendor risk.
- [Risk & Compliance](guides/risk-compliance) — review risks, controls, retention assignments, and related
  assessments.
- [Data Stewardship](guides/data-stewardship) — review dataset ownership, classification, governance cases, and
  assessments.
- [API & Integration Catalog](guides/api-integration-catalog) — browse API specifications, data flows, and API impact.

Each guide describes setup prerequisites, access, available sections, and how the application uses shared entities and
typed relations. Some sections depend on optional bindings or other workspace configuration; the guides call out these
dependencies and any workflow that is still incomplete.
