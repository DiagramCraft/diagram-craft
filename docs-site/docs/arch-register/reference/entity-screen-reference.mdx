# Entity Screen Reference

This page is the compact map of the implemented entity screens.

## Entity Browser Screens

Main capabilities:

- filter and facet browsing
- saved views
- multiple screen modes
- CSV export
- CSV import entry point

## Entity Detail Screens

The entity detail experience includes:

- overview
- topology
- graph
- relationships
- dependents
- related content
- discussions
- assessments
- change history
- timeline

## Browser Modes

The entity browser supports these modes:

- table
- cards
- tree
- graph
- radar
- timeline
- diff
- matrix
- traceability
- path walker
- bubble
- heatmap
- explore
- map

Topology is an entity detail view rather than an entity browser mode. Open an entity and select **Topology** to inspect
its containment, references, and typed relations. See [Entity Relationship Views](../use/entity-relationship-views).
