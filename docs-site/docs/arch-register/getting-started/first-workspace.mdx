# Your First Workspace

## Before you create one

Creating a workspace requires the global permission to create workspaces. If **New workspace** is missing from the
workspace selector, ask a platform administrator for access. Sign-in accounts and workspace membership are managed
separately; see [Identity and Authentication](../admin/identity-and-authentication).

## What a workspace does

A workspace groups schemas, entities, projects, teams, and settings.
It is the main boundary for data in Arch Register.

## Create a workspace

  alt="Workspace selector in Arch Register"

1. Open the workspace selector in the top bar.
2. Choose `New workspace...`.
3. Enter a name and optional description.
4. Choose a blank workspace or a starting template. See [Workspace Templates and Capabilities](../admin/workspace-templates-capabilities)
   to compare template choices and resolve cross-cutting concern mappings.
5. Select `Create workspace`.
