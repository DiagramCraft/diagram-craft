# Getting Started

This path is for people using an existing Arch Register deployment. You can follow it whether you are exploring the
catalog, organizing project work, or preparing a workspace for your team.

## Start from your role

- **Product user:** open your assigned workspace, then follow [Create Your First Entity](first-entity) or
  [Create Your First Project and Diagram](first-project-diagram). Use [Workspace Home and Navigation](../use/workspace-home-navigation)
  to find the main areas.
- **Workspace administrator:** if your workspace does not exist yet and you have permission to create one, follow
  [Your First Workspace](first-workspace). Continue with [Admin Overview](../admin/overview) to configure access and
  shared settings.
- **Integrator:** use the [API and Integrations reference](../reference/api-integrations) for available integration
  surfaces and setup guidance.

## First-use sequence

1. Open an existing workspace. If you cannot access one, ask a workspace administrator to invite you and grant the
   needed access.
2. Learn the workspace layout from [Workspace Home and Navigation](../use/workspace-home-navigation).
3. Create an entity if your workspace has a suitable schema and you have permission to add records.
4. Create a project and diagram if you have permission to create projects.
5. Use [Next Steps](next-steps) to continue with the workflows that match your role.

The repository setup instructions are for developers running a local instance. See
[Local Development Setup](installation) when you need that environment.
