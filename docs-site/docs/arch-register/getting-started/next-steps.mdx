# Next Steps

After you have access to a workspace and know its main areas, choose the next workflow that fits your role.

## Product users

To work with the architecture catalog, continue with [Entities](../use/entities), [Entity Views](../use/entity-views),
[Data Modeling and Schemas](../use/data-modeling-schemas), or [Search](../use/search).

To organize project work and related material, see [Projects](../use/projects), [Assessments](../use/assessments), and
[Content](../use/content).

## Workspace administrators

Configure the workspace model, access, and operational settings from [Admin Overview](../admin/overview),
[Workspace Settings](../admin/workspace-settings), [Roles and Permissions](../admin/roles-permissions), and
[Schemas and Model Overview](../admin/schemas-model-overview).

## Application owners

Check the relevant [Application Guide](../applications/intro) for setup requirements and workflows. Workspace-level
capability configuration and member access are managed in [Workspace Settings](../admin/workspace-settings).

## Integrators

Choose an integration path from [API and Integrations](../reference/api-integrations), then see the focused guides for
[MCP](../reference/mcp-server) or [external integrations](../reference/external-integrations). For access rules and
screen details, see the [Permission Model](../reference/permission-model), [Entity Screen Reference](../reference/entity-screen-reference),
and [Project and Content Screen Reference](../reference/project-content-screen-reference).
