# Search

Use workspace search when you know what you need but not where it lives. It searches the current workspace across
entities, projects, files, schemas, and relation records. Business Glossary has its own alias-aware term search and
quality filters; see [Business Glossary](../applications/guides/business-glossary).

## Workspace Search

Enter a text query in **Search**. Results are grouped into **Entities**, **Projects**, **Diagrams**, **Schemas**, and
**Relations**. The Diagrams group includes searchable content files such as diagrams and Markdown pages. Search matches
record names and descriptions, entity and relation fields, file paths and metadata, and schema names and field names.

Use the category chips to narrow results to one type or return to **All**. Each result shows identifying context such
as its schema, project, folder, owner, lifecycle, matched fields, or content metadata. Select a result to preview it in
the side pane. Use its open action or double-click the row to navigate; the up and down arrows move through results,
and Enter opens the selected result.

Entity results open the entity drawer. Project results open the project, and file results take you to the containing
workspace, entity, or project folder. Schema results open the schema in Settings. Relation results open the related
entity so you can inspect its relationships.

## Business Glossary Term Search

The glossary searches canonical term names, synonyms, and abbreviations. Narrow results with category facets,
quality facets (**Unused**, **Conflicting**, **Deprecated**, or **Missing owner**), and the **Owner / Lifecycle**
filter. Sort by name, usage count, or status. Select a term to open its entity drawer and review its fields and usage;
open the full record in **Entities** to edit it. Glossary search requires the application to be enabled and available
to your account. See the [Business Glossary guide](../applications/guides/business-glossary) for setup and term
maintenance.
