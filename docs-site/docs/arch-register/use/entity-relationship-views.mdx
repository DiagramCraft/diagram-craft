# Entity Relationship Views

These views help you follow relationships between catalog records. Browser views start from the current entity query;
the Topology view starts from one entity's detail screen. Relationship visibility follows your workspace and
field-group permissions.

## Graph

Choose **Graph** in the entity browser's **View** menu to see the matching entities as roots and traverse their
relationships to a configurable depth. Use it to understand a local dependency neighborhood. Generic containment and
reference links and typed relation instances are shown with their relationship types; click an entity to open it, or a
typed relation to inspect its fields and history.

An entity's detail screen also has a **Graph** tab rooted at that entity. Use the browser graph for a filtered set of
roots and the detail graph when you are investigating one record.

## Topology

Open an entity and select its **Topology** tab to see its containment parents and children, incoming and outgoing
references, and typed relations grouped by relation schema. Use it for a compact view of one record's immediate
context. Select a related entity to open it; select a typed relation to inspect its fields and history.

## Explore

Choose **Explore** to compare connected entity sets in adjacent columns. Start with the filtered records in the first
column, then use the relation filter and schema controls to choose how each next column is reached. A column's schema
selection constrains later traversal, so use it to follow a meaningful path through mixed-schema data.

## Matrix

Choose **Matrix** to compare relationship density or coverage across entities. Configure entity columns or attribute
columns, then use populated cells to see where relationships exist and blank cells to spot gaps. A relation-field
filter narrows which connections are counted; hide empty rows or columns when you want to focus on connected records.
Joined assessment select fields can also be used as dimensions for review comparisons. With entity columns, **color by** tints each populated cell by a select field of the row entity, the column
entity, or the typed relation between them, such as a mitigation's effectiveness. A legend lists the field's options and
their colors. For a relation field, the weakest value wins when several relations connect the same pair.

## Traceability

Choose **Traceability** to define one or more relationship paths from the current filtered entities. Add a path label
and select the direction and relationship for each step. The resulting rows show which target records each root
reaches, with architecture coverage and project delivery coverage presented separately. Use this view when you need to
review whether a chain such as controls to risks to assets is complete. See [Projects](projects).

## Path Walker

Choose **Path Walker** to explore one relationship chain interactively without defining the complete path first. The
first column contains the current filtered entities. Select an entity, choose a relationship from the arrow menu, and
continue through the next column; each step narrows the records shown at the next hop. The walker supports up to six
hops and shows where a chain stops when no records match. The selected chain is reflected in the URL; saving the view
also remembers the chosen hop sequence.
