# Schemas And Model Overview

This area defines the structure of the architecture catalog.

## Schemas

Schemas define:

- entity types
- fields
- enums
- references
- containment relationships

Schemas can also include reusable shared fieldgroups. A shared fieldgroup is defined once in workspace settings and
can be included by multiple schemas, keeping its fields consistent when the fieldgroup changes. The default workspace
includes a **PII Classification** fieldgroup with **PII Classification** and **PII Scope**, used by the API, Component,
and System schemas.

Supported field types include text, long text, boolean, date, select, reference, and containment.

## Modeling Guidance

Use:

- reference fields for cross-cutting links
- containment fields for parent-child hierarchy

That distinction matters because containment drives hierarchical views while references drive relationship views.

## Model Overview

Model Overview is the visual companion to schema editing. Use it to inspect how entity types and typed relation types
connect across the workspace rather than only reading form-based definitions. Relation types appear as their own
nodes, with endpoint links and any relation-owned entity links shown around them.
